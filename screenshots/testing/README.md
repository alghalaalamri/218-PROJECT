# Network Testing Screenshots

This folder contains screenshots of the Google Colab tests used to validate the Humanitarian Route Planner's network implementation.

The screenshots document:
- Validation of the original synthetic network.
- Loading and validation of the representative humanitarian network.
- Verification of directed connections, unique leg IDs, and numerical weights.
- Validation of the provided disruption scenario references.

These tests were performed to confirm that the datasets load correctly and are suitable for integration with the routing algorithms.
